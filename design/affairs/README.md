## 导航与反馈合同

- 从校园进入，返回校园并保留搜索；从我的或今天进入同一事务，返回来源列表/日期。内部报告返回事务详情，不能直接跳校园。
- 编辑备注和日期后返回：提供保留草稿/放弃选择；切换账户清理旧账户草稿与实例目标。
- 每个清单项原生触控区域至少44pt，VoiceOver读出“本人勾选，已完成/待核对”；不能只依靠颜色或 Unicode 图案。
- 官方状态始终独立显示“未连接”；自报完成也不出现学校已确认的成功图标。
- 保存时原位置显示进度，防止重复点击；失败保留输入与可恢复错误。来源暂时不可用不抹掉已保存清单。
- 原生页面转场采用系统导航；展开差异约180ms淡入，高度变化尊重减少动态设置；减少动态直接更新，不做位移或庆祝动画。此处是动效交接要求，尚未验证运行效果。
- 目录无数据显示维护状态和官方目录入口；私人列表为空说明“尚未建立清单”；不能把未连接显示为空结果。
- 过期来源显示核对时间、旧版本与原文；停用模板保留既有实例但禁止新建；来源冲突保留差异说明。
