# 登录流程改版 — 交接（2026-10-05 晚）

## 目标

用户 20:07 指出：「连接一次，今天的事都在这里」大卡片不该出现在登录后的「今天」里。应该有一个专门的登录画面，学生用学校邮箱登录；登录完以后「今天」直接显示内容。用户给了参考图（fomo 欢迎页），要求「类似这种的，不过要用学校的邮箱登录」。

已确认的做法（用户选择「按这版做」）：

1. 欢迎页只放品牌和一个「使用学校邮箱登录」按钮。
2. 点按钮后，从底部升起面板，输入学校邮箱，获取验证码。
3. 输入 6 位验证码后登录。第一次登录会自动注册。
4. 登录后，如果还没连接任何学校数据（Canvas 或学校日历），先出现「连接学校数据」这一步。
5. 「连接 Canvas 和日历」打开学校连接页，连好后回来显示已连接，再点「进入今天」；也可以点「稍后再说」直接进入。
6. 已登录的人再次打开 App 直接进「今天」。每次登录都从「今天」开始。
7. 「今天」不再出现大卡片。没有任何安排时显示空的一天，底部保留一行连接入口。

## 没做完 / 不能推定

1. 新页面的深色模式、动态字体、VoiceOver、窄屏（SE 尺寸）没有测。欢迎页固定用海军蓝背景，不随深浅色变化。
2. 真实发信未配置：生产环境需要发信服务，验证码才会真正发到学校邮箱。
3. 后端已有问题（不是本次引入）：在学校连接里断开日历订阅，只删订阅，不删它导入的日程，和页面上「断开后学校数据会从今天移除」的说法不一致。已单独开出后续任务。
4. 底部面板拖动关闭仍无法用模拟器自动操作验证（同上一份交接）。
