# 第一版 iOS MVP — 可粘贴到 Goal 的提示词

在 `/Users/bennie/HKUST/All in one HKUST` 持续完成第一版 iOS MVP，从已完成产品规划推进到真实可运行、可持久化、可验证的本地开发验收版。不要停在方案、静态页面、模拟响应或“可以继续”的说明上。

先读 `docs/superpowers/specs/2026-10-02-ios-mvp-v1-product.md`，它是本 Goal 的范围与完成标准。再按需读取总体设计 v1.2、完整功能路线图、API 文档和现有测试报告。第一版文档优先决定本轮交付范围；长期规划保留，但不把全部远期功能塞进首版。用户已授权文档完成后开始开发，日常可逆实现选择自行决定。

产品目标：学生在一个 iPhone App 中完成学习安排、校园交通与服务查询、低压力活动/学习组队。保持“今天、校园、发现、消息、我的”五入口。社交可选；公共信息允许访客查看；用户不必分享完整课表或先与陌生人聊天。

必须交付：
1. 账户、服务器鉴权、学校资格的真实状态、退出/删除；学校邮箱不能冒充在籍核验。
2. 今天、日/周课表、课程入口、任务、私人短笔记、资料链接，以及带预览/去重/重复例外处理的 ICS 导入。
3. 核验后的核心校巴方向、运行日/假期/末班与过期状态，九巴/小巴相关公开查询，校园地点/服务搜索、详情、收藏及纠错。
4. 活动与学习招募、基础校园墙/求助/回复，报名/候补/退出、组织者改期/取消、名额并发控制及活动评论。
5. 站内通知、许可下的本地日程提醒、个人参与与收藏、受限内容维护和举报后台、轻量官网与公开活动分享页。
6. 真实持久化后端、开发配置、迁移与显式测试数据、可复现启动方式、实际 API 文档、必要测试及 iOS 运行证据。

技术方向：React Native＋Expo＋TypeScript，HeroUI Native 为主组件库候选。先验证当前依赖组合和关键组件，锁定兼容版本；保持统一主题，不叠加多套主 UI 库。官网/后台按需复用现有 Next.js。复用适用的领域逻辑与数据适配器，不能把网页或 MCP 工具当作原生 App 成品。Widget、灵动岛、Watch、iPad/Mac、完整邮件/作业写入、AI 等保留后续；安卓暂不开发。

执行方式：先检查真实仓库状态、模块 AGENTS.md 与已有成果，然后按账户与原生基础→学习安排→校园交通→社交活动→治理与官网→联调验收拆分实施。为当前单元写清实现计划后直接推进，不反复研究已确认方向。只对高影响缺失信息、外部授权或无法自行解决的依赖询问用户；等待期间继续独立可做的工作。不要创建新聊天，不启用子代理，不自行升级模型，不设置 token 硬上限。

数据与边界：学校 SSO、Canvas/SIS、Graph 私人数据及校巴 GPS 只走获批接入；未获批就展示缺口和可用替代路径。公开数据保留来源、时间和失效状态。开发模式允许显式标记的本地测试账户、邮件适配器与演示活动，须与真实内容隔离并禁止进入公开生产配置；不能冒充真实用户、学生资格、活动供给或正式邮件服务。任何未实现操作不能显示成功。

不擅自部署、发布、购买服务、创建外部账户、收取学校密码、发送真实消息/邮件、提交作业、删除无关文件或修改全局插件。需要这类动作时先做好可审阅交付，再明确提出具体请求。

完成标准：通过首版文档 MV01–MV12。真实运行后端与 iOS App，在模拟器或获准 iPhone 上完成学习、交通、活动三条流程并保存截图/证据；验证跨账户隔离、重启持久化、ICS 例外、校巴边界、报名并发、取消后提醒失效、举报与删除、弱网/空状态/键盘/字体放大。旧测试或纯网页预览不能替代这些验收。

先检查 Xcode/SDK/模拟器与真机路径。当前记录仅有命令行工具，标准路径未发现完整 Xcode；若仍缺少可用 iOS 环境，明确需要用户完成什么，继续后端和其他可验证工作，不能宣称 iOS 已通过或将 Goal 标记完成。其他阻塞同样保留证据，不伪造通过。
