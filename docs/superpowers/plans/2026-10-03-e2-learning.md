# E2 Learning Implementation Plan

> Execute inline with superpowers:executing-plans and test-driven-development. User authorizes implementation and prohibits subagents.

**Goal:** Real private learning workflow: courses, day/week schedule, tasks, notes/material links and previewed ICS import.
**Architecture:** Add versioned SQLite learning records owned by the authenticated account. A separate route module handles validation and transactions, then native screens consume its contract. Preserve source identity for the later ICS import layer without treating imported courses as enrolment.
**Tech Stack:** Existing Node/SQLite/Zod/Fastify and Expo/HeroUI Native; no new dependencies for the manual-record unit.
**Spec:** `docs/superpowers/specs/2026-10-02-ios-mvp-v1-product.md`, V02/V03, MV02–MV04/MV08–MV11; detailed semantics in `2026-10-02-super-app-day-and-identity-design.md`.

## Constraints / review focus

- Every query/mutation/export scoped to authenticated owner; foreign course IDs return 404.
- Dates without a time remain dates; all-day ends are exclusive, missing end remains unknown.
- Create retries use an atomic owner-scoped Idempotency-Key; edits/deletes require expected version.
- Deleting a course detaches its records, preserving independent tasks/notes/links; account deletion cascades everything.
- Cancellation/completion/changes increment versions; reminders consume only current applicable records in E5.
