# Super App：功能范围与验收清单

日期：2026-10-02｜版本：1.2｜状态：长期功能范围已按用户要求扩充，全部产品验收待执行。配套 [总体设计](2026-10-02-hkust-super-app-design.md)、[U0 设计](2026-10-02-super-app-day-and-identity-design.md)及[全量功能账本 B01–B50](2026-10-02-bnbu-full-feature-roadmap.md)。

## 1. 如何使用本清单

R1 = iOS 首个真实试用版本；R2 = 完整学校能力与 iOS 深化；R3 = 多校/全港和其他苹果设备扩展，两者可独立排序；R4 = 更深 AI、复杂系统体验与其他平台。阶段表示交付先后，不是重要性或已开发状态。用户要求的参考功能全部保留为长期范围；Android/Windows 暂缓且未授权启动，历史停用能力单独记录。新增能力以全量账本为准，不能因原清单未列而遗漏。

接入深度分别记录：原生可完成、授权同步、用户导入、官方办理入口、尚未覆盖。来源提供一个网址不能算授权同步；模块有旧代码不能算已验收。

首试是否从 HKUST 开始为当前推荐，等待用户偏好；若改为多校或全港首发，需增加来源和组织供给，不能自动降低学习与生活范围。总体验收覆盖学习、生活、社交三条流程。选择理由、独立留存、增长假设与试点口径见 [策略设计](2026-10-02-super-app-value-retention-growth.md)；功能验收通过不等于需求已验证。

## 9. 必须通过的跨模块验收场景

以下为未来产品验收要求，本轮没有运行这些测试。

本表 T01–T21 继续有效；新增 T22–T31 已登记在[全量功能路线图第 6 节](2026-10-02-bnbu-full-feature-roadmap.md#6-新增验收追踪)，覆盖作业写入、成绩/邮件隐私、身份卡、系统组件、跨端和 AI，均未执行。

| 场景 | 应观察到的结果 |
| --- | --- |
| T01 A/B 两个账户查看、搜索、导出个人日程/笔记 | B 无法看到或根据摘要推断 A 的私有内容 |
| T02 同一 ICS 重导，含周课、取消一节、改一节、全天事项 | 不重复，例外正确，时区与日期语义保持；不支持项逐条说明 |
| T03 导入文件缺少之前的一条课程 | 不静默删除旧记录，用户可核对是否是完整替换 |
| T04 邮箱来源只有主题和基础日历字段 | 界面不声称已读完整作业正文或全部课程消息 |
| T05 班车不运行、时刻已过期或 ETA 中断 | 明确不同状态，不继续虚假实时倒计时 |
| T06 从讲座详情加入同行小组 | 同行成功与官方报名分开，原报名状态未知时仍为未知 |
| T07 两人同时争取最后一个活动名额，并重复提交请求 | 只有一个名额被占用；另一人收到真实满员/候补结果 |
| T08 已报名活动改期或取消 | 受影响者收到正确说明，旧提醒撤销，必要时重新确认 |
| T09 从同校切换全港，并尝试打开别校成员帖子 | 筛选不扩大权限；旧校园内容不被重新发布 |
| T10 学校资格失效或毕业 | 个人自建资料与城市账户保留；机构权限按规则变化 |
| T11 用户退订、屏蔽、退出圈子、撤销来源 | 搜索、推荐、缓存、通知与后台状态一致，无继续越权读取 |
| T12 参与者取消、候补超时、组织者未成团 | 名额和状态正确，规则可理解，无公开羞辱 |
| T13 资料共享给学习组后撤回（R1 链接与笔记；R2 含文件） | 本平台新请求、下载和搜索不再授予组访问；外部链接由原站控制，已合法下载副本的限制事先说明 |
| T14 首次来的人完成一场活动流程 | 能说清地点、语言、费用、接应和退出方式，反馈是否符合预期 |
| T15 组织者复制上一场活动 | 可复用描述与模板，日期需确认，旧参与者不会自动报名 |
| T16 原要求更新，同时任务有本人笔记和日期覆盖 | 提醒核对、保留个人输入；相关招募只共享主动选择内容 |
| T17 筛选可参加活动，但结束时间、语言或资格缺失 | 显示待确认，不宣称匹配或擅自放松必要条件 |
| T18 留下意向后撤回，或组织者提出具体方案 | 不占名额；未经新确认不报名；撤回后停止撮合和相关通知 |
| T19 私密邀请被转发或撤销，搜索引擎尝试读取预览 | 原权限持续生效，预览不泄露任务、课表和名单，撤销可验证 |
| T20 试用者未回复、活动取消或没有下一场供给 | 未知/取消/缺口分别记录；不移出留存分母美化指标，导出按最小权限 |
| T21 外部 ICS 包含候补或申请中的活动 | 日程存在不表示报名成功；无法可靠识别时参与状态未知，不显示已加入 |
