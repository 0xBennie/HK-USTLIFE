## 2. 阶段与状态

- R1：iOS 首个真实试用版本，学习、生活、社交三条流程均可用。
- R2：学校深度接入与 iOS 体验完善；学校读写权限分别申请，未批准仍登记缺口。
- R3：多校/全港与其他苹果设备扩展，两条工作流可独立排序，不要求等全港完成才做 iPad/Mac。
- R4：更深 AI、复杂系统体验和其他平台；列入长期范围，不因后置而自动删除。
- G：外部批准、系统支持或专项审阅是交付条件，不是已经获得。
- H：参考产品已停用的历史能力，仅保留评估记录，不能标为现行竞品功能。

用户已确认 iOS 优先，安卓暂不开发。Android/Windows 保留远期平台占位，不进入当前开发与验收任务。Apple Watch、iPad、Mac 不因此被删除，也不挤入 iPhone 首版。下表全部为未实施的范围项；已有工具或文档不能抵扣产品验收。

## 4. 五入口与系统入口

今天承接课表、课程/资料、任务和摘要；校园承接地图、交通、生活目录、学院部门与办理；发现承接校园墙、学习组队、圈子和全港活动；消息承接系统变更、社交互动，并提供独立“学校邮件”入口；我的承接身份卡、成绩入口、个性化、设备/同步、授权和数据管理。

学校邮件与社交私信不是一个收件箱，不能因打开消息页自动读取私人正文。成绩也不默认出现在首页、锁屏或 AI 上下文。AI 从搜索、课程和用户主动调用进入，可有独立会话页；不替代五入口。小组件、灵动岛、Watch 是同一安排数据的系统呈现，不另维护一套截止事实。

## 5. 新增依赖与 API 工作项

现有 OpenAPI 0.1 的 48 个拟议操作尚未覆盖本文件全部需求，也未实施。本轮不虚构正式学校地址或权限。新增合同按以下包深化：

| 包 | 需要补充的合同 | 前置条件 |
| --- | --- | --- |
| 原生身份与设备 | 手机授权回调、设备会话、撤销、通知 token、深链接 | iOS 登录方案、测试后端、学校批准 |
| 学习资料与写入 | 章节/文件/下载/打包、作业预览/提交/回执、成绩读取 | Canvas/SIS 逐能力批准；文件与提交完整性 |
| 邮件 | 列表/正文/附件、草稿、发送/转发、删除/恢复、雷达同意与派生记录 | Graph 等来源的分别授权，不能沿用基础读取 scope 做写入 |
| 校园与身份卡 | 人员目录、地点/标记、评价/纠错、个人卡与 Wallet 签发 | 公开内容使用权、学校资料权限、卡片用途与签发审核 |
| 跨端系统体验 | 最小日程快照、版本/失效、提醒规则、同步冲突/删除 | iOS 主记录与权限稳定、设备专属验收 |
| AI | 受限读取、附件、动作预览/确认、会话/记忆/删除、用量 | 清楚的数据处理方式及费用，已验收的基础业务动作 |

使用学校官方认证与获批连接，不复制参考产品说明中的密码收集/会话复用方式。平台账号、学校资格、来源授权继续分离。长期纳入作业提交和邮件发送是功能规划，不授权当前会话发送邮件、提交作业或连接个人账户。

## 7. 本阶段交接
