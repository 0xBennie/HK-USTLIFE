# 向 Luma 学什么（2026-10-05）

看过的页面（手机尺寸，luma.com）：探索页、香港城市页、活动详情（开放报名 / 已满候补 / 付费）、创建活动页、社区日历页。
原则：吸收做法，不照搬样子；继续用我们的 Liquid Glass 控件、单一海军蓝和五个主入口。

## 值得学的

| # | Luma 的做法 | 我们现在 | 怎么用到我们这里 |
| --- | --- | --- | --- |
| 1 | 详情页一张「报名」卡，按状态只给一个下一步：开放→报名；已满→说明+加入候补；付费→价格 | 「报名已确认」在标题下、发起人行、底栏重复出现 3 次；底栏按钮看起来像禁用 | V6 / 活动详情（报名卡）+ 报名卡 · 其他状态 |
| 2 | 日期用小日历方块（月 + 日），地点一行带图标 | 四行信息卡，日期没有视觉锚点 | 日历方块 + 地点行 |
| 3 | 创建页一屏：大号行内标题、开始/结束两行用选择器、选项分组成「名称—当前值 ›」 | 每个选项是一整行大按钮；时间要手打 YYYY-MM-DD HH:mm；按钮写「发布演示活动」 | V6 / 发起活动（一页表单） |
| 4 | 次要动作很安静：「联系主办人 / 举报活动」是页尾灰字 | 「举报 / 屏蔽」蓝色大字出现两次；提醒时间 5 个大胶囊占半屏 | 页尾一行灰字；提醒收成报名卡里的一个按钮 |
| 5 | 列表按日期分组，时间在前、标题加粗、主办人与地点各一行，状态/价格用小标签 | 「全部活动」行信息少 | 下一步：按日期分组 + 状态小标签（另画板） |
| 6 | 分类显示数量（如「游戏 466 场活动」），让人知道值不值得点 | 校园墙话题、社团分类没有数量 | 话题、社团分类、官方活动显示真实数量 |
| 7 | 从列表打开活动是一个可上下翻的面板，不跳出当前页 | 科大官方活动点一下直接跳 Safari | 先在 App 内面板看时间/地点/主办，再「打开官方页面」 |

**进度（2026-10-05）**：1–7 全部已在 App 实现并在模拟器核对，对照图见 `docs/progress/evidence/native-ui-refresh/v6-activity/`。
- 1–4：报名卡全部状态、确认报名面板、活动讨论页、一页表单、页尾灰字举报。
- 5：「全部活动」按香港日期分组，时间在前，标签只说状态（已确认/候补/还剩 N 位）和价格。
- 6：科大官方活动「在校园 58 / 全部 75」、社团「全部 82 / 运动 34 / 文化 12 / 兴趣 16 / 院系 16 / 舍堂 4」，数字由已加载的真实数据现算；加载失败时不显示数字。
- 7：官方活动点开是 App 内面板（日期、时间、地点、主办），再「打开官方页面」。

## 不学的（和我们原则冲突）

- **按封面换整页底色**（奶油、暗红、墨绿）：我们只用海军蓝做强调，颜色只表达状态。
- **公开参加者头像和名字**（「Richard Chu、Charlie 和其他 74 人」）：我们的后端只让发起人看名单，参与者只看到人数。
- **城市/全球浏览、订阅邮箱**：我们是 HKUST 单校，没有这个场景。
- **付费购票、需要审核**：后端还没有审核制报名和平台支付，不画假选项（见 PRD E02/E06）。
