# UI 审核 V4：为什么"普通"、要怎么改（2026-10-04）

审核对象：模拟器上的 V3 原生实现 + Pen V3 画板。评判标准：一个科大学生第一次打开，会不会觉得"这个 app 有设计感、值得天天用"。

## 一、配色（已在 Pen 完成第一步）

| 问题 | 处理 |
|---|---|
| 粉/薄荷/淡紫/蜜桃四色极光同时出现，糖纸感 | 改为单一冷雾蓝底（#F2F4F7 + 极淡蓝/米色光晕） |
| 头像亮粉、话题泡泡五种饱和渐变、图标圆块七八种颜色，没有主色 | 主色 = HKUST 海军蓝 #24467F；辅色 = 石板灰 #56647D、哑金 #A9824C |
| 饱和红绿橙用于装饰 | 只留给状态：逾期 #E5484D、完成 #2E9E5B、提醒 #D98A1C |
| "下一节"卡片和背景同色，没有焦点 | 改为全页唯一的深海军蓝渐变卡，白字 |

## 二、"low" 的根因（不是颜色）

1. **每页都是同一种组件**：白色圆角卡 + 列表行 + 圆形图标块。像"设置"App，换哪个 tab 都一样。
2. **Hero 大数字被复用到烂**：今天"2 项"、校园"18:00"、消息"3 条"，三个 tab 一个模板，信息密度低、没有画面。
3. **假玻璃**：半透明白底没有真实模糊/折射；Tab bar 不是 iOS 原生 Liquid Glass，和系统一比就廉价。
4. **零动效签名**：数字不滚动、完成没有触感、列表不能滑动操作、页面切换没有连续性。
5. **数据被做成表单**：校巴是两行列表（应是发车看板+倒计时环）；截止是清单（应是时间轴+紧迫度）；一天的安排没有"时间"的视觉。
6. **字体单一**：全部系统默认字重，数字没有独立字形，标题和正文对比弱。
7. **图标是剪贴画**：线性图标塞进实心圆，全 app 几十个一模一样的"圆块"。
8. **逻辑/文案 bug**：校园 Hero 显示"下一班 18:00"，下方却写"周一·今天没有校巴"，看不出是哪天。

## 三、改造方案（先 Pen 后原生）

| 优先 | 改造 | 用在哪 |
|---|---|---|
| P0 | **原生 Liquid Glass**（tab bar、圆按钮、浮层），替代假玻璃 | 全局 |
| P0 | **今天：一日时间轴**——横向时间带，课程是色块、截止是图钉、红色"现在"线；下一项用倒计时环 | 今天 |
| P0 | **校园：发车看板**——翻牌式滚动数字、实时脉冲点、到站倒计时环；修正"哪天"文案 | 校园 |
| P0 | **触感 + 滚动数字 + 按压回弹**统一接入 | 全局 |
| P1 | **截止行左滑完成 / 右滑延后**，完成时勾选动画 + 触感 | 今天、学习 |
| P1 | **缓慢流动的极光背景**（Skia 网格渐变，减少动效时静止） | 全局 |
| P1 | **数字用 SF Rounded**，标题加大字重对比 | 全局 |
| P1 | **校园墙**：话题改成"故事圈"样式、图片优先卡片、长按原生菜单 | 校园墙 |
